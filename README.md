# comsoc_frontend

Frontend application for the ComSoc project.

## Development

1. Clone the repository and open it in your editor.
2. Install the project's dependencies using the package manager defined by the repository.
3. Start the frontend with the existing project start script.

## Maintainability

Keep reusable UI components separated from page-specific code, avoid committing generated build output, and update this README when the setup or development workflow changes.
